# Security policy

## Supported versions

Security fixes go into the latest release. Installs with automatic updates turned on get them at night.

## Reporting a problem

Please do not open a public issue for a security problem.

Report it privately on GitHub: [open a security advisory](https://github.com/meroxis/nuvabill/security/advisories/new).
Include the Nuvabill version, the steps to reproduce, and what an attacker could do.

We will reply as soon as we can, keep you updated while we work on a fix, and credit you in the release notes
if you want.
